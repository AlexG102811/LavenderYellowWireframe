# QuizWave

Test your knowledge. Ride the wave.

## Overview

QuizWave is an authentication and user management portal written in React with TypeScript and Vite. It preserves the lavender & yellow wireframe aesthetic and client-side authentication logic.

## Features

- **Authentication System**:
  - Sign in with username and password validation
  - Sign up with minimum length rules and password matching
  - "Remember me" persistent session handling
  - Guest exploration mode
  - In-app notification modals (replaces browser alerts for seamless iframe compatibility)
- **Active Session Dashboard**:
  - Displays currently logged-in account or guest session
  - Session timestamp and status
  - One-click sign out / switch account
- **Responsive Lavender & Yellow Theme**:
  - Retains all visual design tokens, fonts, cards, and transitions.

## Tech Stack

- React 19
- TypeScript
- Vite
